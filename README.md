# Project_notesRecognising

Проект "Навчальна програма з музичної теорії"

Звіт з виконання проекту знаходиться у файлі REPORT.md (минулий звіт скопійовано туди, актуальний йде після нього)

Інструкція по запуску:
Необхідно: компілятор MSVC (встановлена VisualStudio з компонентом "Розробка класичних додатків на C++")
1) Відкрити корінь проекту
2) Відкрити термінал
3) Прописати команду .\build.bat
4) Якщо після прописування команди видало помилку: [ERROR] MSVC compiler not found. Run from Developer Command Prompt for VS:
    1) Відкрити Developer Command Prompt for VS
    2) Вказати директорію в якій знаходиться папка проекту: cd "С:шлях\до\папки"
    3) Прописати команду .\build.bat
Для запуску Unit-tests та benchmarks інструкція аналогічна, але замість .\build.bat необхідно прописувати команди .\run_tests.bat .\run_bench.bat відповідно

Для генерації документації прописати в термінал команду doxygen

Після закриття сайту для повернення терміналу до початкового вигляду натиснути CTRL + C -> Y
