# Project_notesRecognising

Проект "Навчальна програма з музичної теорії"

Звіт з виконання проекту знаходиться у файлі REPORT.md (минулий звіт скопійовано туди, актуальний йде після нього)

Інструкція по запуску:
Необхідно: компілятор MSVC (встановлена VisualStudio з компонентом "Розробка класичних додатків на C++")
1) Відкрити корінь проекту
2) Відкрити термінал
3) Прописати команду .\build.bat

Щоб запустити Unit-tests: прописати в термінал команду .\run_tests.bat
